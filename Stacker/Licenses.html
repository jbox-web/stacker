    module Stacker::Licenses

    Overview

    The third-party notices the released binary has to carry, embedded at compile time. A statically linked binary contains its dependencies' code, so it has to contain their notices too.

    Embedded with the stdlib macros alone (read_file plus a backtick ls), as crystalreleaser does.

    The folder is generated by scripts/harvest-licenses.sh (mise dev:licenses) from licenses.manifest, and is gitignored. It has to exist before this file is compiled, which is why every compiling task declares that script as a dependency. An empty or missing folder is a compile error by design: a binary shipped without its notices is the failure this module exists to prevent.
